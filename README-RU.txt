ВОСТОЧНАЯ ЕВРОПА — локальная версия карты

Запуск: откройте GitHub Pages или запустите локально командой python -m http.server 8000 и откройте http://localhost:8000.

Географические данные не скачиваются. Геометрия 32 игровых региона встроена в provinces.js. Карта является схематической игровой иллюстрацией: границы, формы и расположение регионов не являются точными географическими или административными данными. Не используйте её как историческую карту или для определения реального контроля территорий.

Выбор страны, выбор региона, поиск, масштабирование, перетаскивание и локальные сохранения остаются доступны.
