# Восточная Европа: Стратегия 2022–2026

Новый браузерный прототип с интерактивной SVG-картой административных единиц России, Украины и Беларуси.

## Запуск

1. Распакуйте архив.
2. Откройте терминал в папке `east-europe-strategy`.
3. Запустите локальный HTTP-сервер, например `python -m http.server 8000`.
4. Откройте `http://localhost:8000`.
5. При первом запуске нужен интернет: приложение загружает ADM1 GeoJSON из открытого репозитория geoBoundaries. Браузерный запуск через `file://` не поддерживается из-за ES-модулей и CORS.

Геоданные не включены в архив как будто они уже проверены: в среде сборки отсутствовал сетевой доступ. Поэтому карта получает реальные полигоны по URL во время запуска; если источник недоступен, интерфейс явно сообщает об ошибке и не подменяет географию декоративными фигурами.

## Географические источники и лицензия

- geoBoundaries, gbOpen, ADM1 для `RUS`, `UKR`, `BLR`: `https://www.geoboundaries.org/`
- Публичные GeoJSON URL указаны в `js/countries.js`.
- Набор geoBoundaries предоставляет открытые границы под лицензией CC BY 4.0; перед публичным распространением проверьте актуальные условия и сведения конкретного набора на странице метаданных. В приложении оставлена атрибуция.
- Точность и полнота административных единиц зависят от версии исходного набора. Набор ADM1 — административные регионы первого уровня, а не подробные игровые провинции.

## Реализовано

- Новая структура проекта без зависимости от предыдущих файлов.
- Загрузка GeoJSON административных единиц трёх стран; стабильные ID создаются из кода страны и slug названия с устранением дублей.
- Отрисовка геометрии SVG с проекцией Web Mercator, заливка по владельцу, подсветка выбранной единицы.
- Выбор провинции, информационная панель, поиск с переходом к результату.
- Масштабирование колесом мыши и кнопками, перетаскивание мышью/касанием, сброс масштаба, центрирование на найденном регионе.
- Выбор страны, тестовый сценарий, дата и кнопка хода.
- Переключение режимов карты (экономические/ресурсные слои честно помечены как неподготовленные).
- Локальное сохранение кампании в localStorage и продолжение.
- Адаптивный интерфейс для узкого экрана.

## Пока не реализовано

- Геоданные не запакованы локально и требуют доступа к источнику при первом запуске.
- Детальные стратегические провинции, города и подписи городов.
- Исторически выверенные линии фактического контроля для разных дат; текущий сценарий намеренно не заявляет точность контроля.
- Армии, здания, экономика, ресурсы, производство, исследования и дипломатия.
- Автоматические тесты взаимодействия в реальном браузере.

## Структура

- `index.html`, `styles.css`
- `js/main.js`, `gameState.js`, `mapRenderer.js`, `mapInteraction.js`, `provinces.js`, `countries.js`, `scenarios.js`, `saveSystem.js`, `ui.js`
- `data/` — зарезервирована под локальные GeoJSON и сценарии
- `scripts/` — зарезервирована под импорт/подготовку геоданных
