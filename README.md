# Восточная Европа — локальная карта

This version contains a **hand-drawn schematic game map** embedded in `provinces.js`; it makes no external geography requests and does not need GeoJSON downloads.

**Accuracy notice:** the shapes and internal boundaries are illustrative and are not official or geographically accurate administrative boundaries. This is a local gameplay prototype, not a factual territorial-control map.

Run locally with `python -m http.server 8000`, then open `http://localhost:8000`. On GitHub Pages, publish the repository root.
